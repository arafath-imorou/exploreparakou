# Explore Parakou 🇧🇯

**Explore Parakou** est une plateforme institutionnelle et touristique dédiée à la promotion de la ville de Parakou, "Le Cœur battant du Bénin". Ce projet vise à mettre en valeur le patrimoine, le dynamisme économique et la richesse culturelle de la cité des Kobourou.

## 🚀 Structure du Projet

Le site est composé de 8 pages interconnectées :

- **`index.html`** : Page d'accueil immersive (Landing Page).
- **`decouvrir.html`** : Histoire, quartiers emblématiques et monuments.
- **`tourisme.html`** : Guide des hôtels, restaurants et sites naturels.
- **`culture.html`** : Arts, artisanat et festivals locaux.
- **`agenda.html`** : Calendrier des événements culturels et économiques.
- **`carte.html`** : Interface de carte interactive (Maquette).
- **`investir.html`** : Opportunités économiques et secteurs porteurs.
- **`medias.html`** : Galerie photos immersive, vidéothèque et espace presse.
- **`contact.html`** : Formulaire de contact et informations administratives.

## 📦 Visualisation du Site

Puisque **Python** et **Node.js** ne semblent pas installés sur votre machine, voici les méthodes simples pour voir le site :

### Méthode 1 : Ouverture Directe (Simple)
1. Allez dans le dossier `ExploreParakou`.
2. Double-cliquez sur le fichier **`index.html`**.
3. Le site s'ouvrira dans votre navigateur par défaut.

### Méthode 2 : VS Code (Recommandé)
Si vous utilisez Visual Studio Code :
1. Installez l'extension **"Live Server"**.
2. Faites un clic droit sur `index.html`.
3. Choisissez **"Open with Live Server"**.
